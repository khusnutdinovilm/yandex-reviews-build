### Added

#### Авторизация и API

- SPA-аутентификация через Laravel Sanctum (cookie/session-based): вход
  `POST /login`, выход `POST /logout`, защищённый `GET /api/user`.
- Stateful-режим Sanctum для доверенных доменов (`SANCTUM_STATEFUL_DOMAINS`),
  регенерация сессии при входе (защита от session fixation).
- Слой API (`routes/api.php`) с группой маршрутов под `auth:sanctum`.
- Сид-пользователь для входа: `admin@example.com` / `password` (идемпотентный
  сидер).

#### Фронтенд (SPA)

- Одностраничное приложение на Vue 3 (Composition API) с TypeScript; статическая
  проверка типов через `vue-tsc`.
- Интерфейс на PrimeVue 4 с тёмной темой (пресет Aura с зелёным акцентом).
- Упрощённая FSD-архитектура фронтенда (`app` / `pages` / `shared`) с публичными
  API через `index.ts`.
- Клиентская маршрутизация на Vue Router с ленивой загрузкой страниц; клиентские
  маршруты переживают перезагрузку страницы (catch-all fallback на стороне
  Laravel).
- Поддержка SCSS: глобальные стили и автоматическое подключение общих
  токенов/миксинов в компоненты.
- SPA отдаётся самим Laravel (один origin) через Blade-обёртку и Vite — CORS не
  требуется.

#### Инфраструктура и деплой

- Локальное окружение в Docker через Laravel Sail: PHP 8.4 + MySQL + dev-сервер
  Vite с HMR (поднимается одной командой `sail up`).
- Прод-сборка в Docker: многоступенчатый образ (сборка ассетов → зависимости
  Composer → PHP-FPM), nginx с gzip и иммутабельным кэшированием собранных
  ассетов, включённый OPcache; `docker-compose.prod.yml` (app + nginx + MySQL,
  один origin).
- Автодеплой на сервер через GitHub Actions при мерже в `main` (SSH +
  `docker compose up -d --build`, миграции и кэширование конфигов/маршрутов/
  представлений).
- CI на pull request: проверка форматирования (Prettier), типов (`vue-tsc`) и
  сборки фронтенда до мержа.
- Prettier для форматирования фронтенда и шаблон Pull Request.
- README с инструкцией по локальному запуску и учётными данными сид-пользователя;
  ведение этого CHANGELOG.

### Changed

- База данных по умолчанию — MySQL (через Sail); драйвер сессий — `database`.

### Removed

- Стартовая страница-заглушка Laravel (заменена на SPA-обёртку).
